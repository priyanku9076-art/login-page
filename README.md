# Login Page

A visually appealing and user-friendly login page featuring a split layout with an illustration on one side and an interactive authentication form on the other.

## 📋 Features & Requirements
- **Container Setup:** Designed with a container height of `100vh` and centered perfectly using **Flexbox** instead of traditional margin or padding tricks.
- **Split Layout:** Divided into a left section with an illustration and a right section hosting the login form.
- **Interactive Form Elements:** Includes a friendly heading ("Hello Again!"), styled email and password input fields with custom placeholders, and an attractive "Login" button.
- **Pure CSS Implementation:** Built using custom CSS (`index.css`) without Bootstrap or external frameworks.

## 🛠️ Technologies Used
- HTML
- CSS3 (Flexbox, Viewport Units)
